# MyLms 시험 모듈 — 1페이지 요약(간소화 구조)

## 목적

객관식 기반 시험을 **엑셀→업로드→응시→자동채점→리뷰/다운로드**까지 단순한 흐름으로 운영.

엑셀 저장 방법
엑셀 컬럼에 맞게 데이터 입력 후 다른 이름으로 저장 저장 경로 선택 후 
파일 형식 CSV(쉼표로 분리)(*.csv)로 선택
추가로 저장 버튼 옆에 도구(L) -> 웹 옵션 -> 인코딩 -> 문서를 다음 형식으로 저장(S) -> 유니코드(UTF-8)로 설정 -> 항상 기본 인코딩 형식으로 웹 페이지 저장(A) 체크 -> 확인 -> 저장 후 CSV파일 업로드

---

## 역할 & 한 줄 요약

* **관리자**: 엑셀 템플릿 배포(형식 통일)
* **강사**: 템플릿으로 문제 작성→엑셀 업로드→시험 회차 열고 닫기
* **학생**: 시험 보기(타이머)-시험페이지 → 제출→결과(다운로드 가능)

## 파일 포맷(엑셀)

* **Questions 시트**: `Q_NO | TYPE | STEM | POINTS`
* **Choices 시트**: `Q_NO | CHOICE_NO | TEXT | IS_ANSWER(TRUE/FALSE)`

> 업로드시 검증: SINGLE 정답=1개, MULTI 정답≥1개.

---

## 핵심 흐름(5단계)

1. **관리자**: 템플릿 제공
2. **강사**: 템플릿 작성 후 **업로드** → 서버가 **유효성 검사 + 미리보기**
3. **강사**: 시험 **회차 생성**(시간/부분점수 옵션) 후 **공개**
4. **학생**: 시험 **응시**(타이머·선다형 UI) → **제출**
5. **서버**: 즉시 **자동채점** → **리뷰 페이지/다운로드** 제공

---

## 자동채점 규칙(간단)

* SINGLE: 선택 == 정답이면 득점, 아니면 0점
* MULTI: (옵션) 부분점수, 오선택 페널티 가능

---

## 화면(최소)

* **강사**: 시험목록 / 엑셀업로드 미리보기 / 회차설정 / (선택) 재채점
* **학생**: 시험목록 / 시험보기(타이머) / 결과·정오표 보기·다운로드

---

## 엔드포인트(대표)

* 강사: `GET /teacher/exams`, `POST /teacher/exams/upload`, `POST /teacher/exams/{id}/sessions`
* 학생: `GET /student/exams`, `GET /student/exams/{sessionId}/take`, `POST /student/exams/{sessionId}/submit`, `GET /student/submissions/{id}/review`

실시간 영상 작업 

1) 도메인 분리

실시간 강의: liveclass/*

VOD 강의: vodclass/*

공통: 코스/권한/수강 여부는 기존 로직 재사용

2) 데이터 구조

course (공통): id, title, teacher_id, ...

live_session: id, course_id, title, starts_at, ends_at, provider(YOUTUBE|HLS), youtube_live_id, hls_url, status(SCHEDULED|LIVE|ENDED)

vod_item: id, course_id, title, video_url, duration_sec, position

3) 라우팅

실시간 목록: GET /liveclass/sessions?courseId={id}

실시간 입장: GET /liveclass/room?sessionId={id}

VOD 목차: GET /vodclass/chapters?courseId={id}

VOD 재생: GET /vodclass/room?courseId={id}&itemId={id}

4) 화면(플레이어 영역만)

실시간: YouTube iframe(또는 HLS 플레이어) 표시 + LIVE 배지

VOD: 기존 <video> 플레이어(배속/탐색/이어보기)

5) 역할 플로우

강사

실시간: 세션 생성(시간/제목/공급자/ID/URL) → 시작 시간에 방송

VOD: 목차 항목 CRUD(제목/영상 URL/순서/길이)

학생

실시간: 세션 목록 → ‘입장’ → 라이브 플레이어 시청

VOD: 목차 → 항목 선택 → 재생

6) 권한/보안

세션/목차 조회·입장: 수강자 권한 체크

실시간 세션 생성/수정: TEACHER/ADMIN만

YouTube 사용 시 Unlisted 권장 / HLS는 토큰화된 URL 고려

7) 예외 처리(요약)

라이브 대기/종료: 상태에 따라 버튼/안내문만 변경

YouTube 차단 환경: HLS 대안 안내

8) 한 줄 요약

실시간은 live_session+임베드, VOD는 vod_item+기존 플레이어.
라우트·테이블·화면을 완전히 분리해 운영하되, 코스/권한은 공통 사용.
